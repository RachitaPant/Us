# Us 💙  
**Inspired by my amazing roommates of Bhagirathi 101**

A simple yet special website built with love, laughter, and a bit of HTML, CSS, and raw JavaScript.  
This project is a digital memory lane dedicated to the moments we shared, the inside jokes, the late-night talks, and everything in between.

---

## 💡 What is *Us*?

*Us* is more than just a website — it’s a tribute.  
It captures the spirit of friendship and memories created in Bhagirathi 101, lovingly coded from scratch without any frameworks or libraries.

---

## 🛠️ Tech Stack

- **HTML** – Structure of the memories  
- **CSS** – Styled with care  
- **JavaScript** – Just enough to bring the memories to life
